# Legacy NPZ scripts

This directory contains older NPZ-based scripts used during early development.

The current large-scale workflow uses HDF5 and is based on:

- `scripts/generate_bbh_dataset_hdf5.py`
- `scripts/create_hdf5_splits.py`
- `scripts/train_cnn_hdf5.py`

The scripts in this directory are kept for reference and small debugging experiments, but they are not part of the official large-scale workflow.

They may contain older assumptions, hardcoded paths, or naming conventions from early experiments.
