# Audit notebooks

This directory contains exploratory audit notebooks used to inspect specific parts of the CBC-PE workflow.

These notebooks are not part of the main tutorial path.

Main official notebooks are kept one level above:

- `01_signal_generation_demo.ipynb`
- `02_cnn_training_hdf5_demo.ipynb`
- `03_cnn_evaluation_hdf5_demo.ipynb`
- `04_mondrian_hdf5_demo.ipynb`

Audit notebooks may contain local paths, exploratory checks, and temporary diagnostics. They should be cleaned before being used as public tutorials.
